`packages/shared/src/discovery.ts` defines provider identity, search capabilities, types, restrictions, results and selected detail. Results explicitly distinguish metadata, temporary preview and importable content. LRCLIB search/detail remain temporary previews; selected usable detail carries a server-signed personal-import receipt. Lyrics-only provider does not fabricate chord/tab availability. A `mixed` request can return the available lyrics portion, not a mixed-content claim; chords/tab filters return no results.

Routes follow existing `/api/v1`: `GET /discovery/providers`, `GET /discovery/search`, `GET /discovery/results/:providerId/:resultId`. Strict Zod validation rejects unknown query fields, unknown providers, arbitrary URLs, unsupported pagination, oversized inputs and invalid record IDs. Search accepts `q`, `title`, `artist`, `album`, `provider`, `contentType`, `limit` (1–20). Search and detail use dependency-injected providers for reproducible tests, fixed provider endpoints for production and `Cache-Control: no-store`. No source URL becomes a fetch destination. A per-process 30 requests/minute/IP guard complements the provider's shared serial queue and server-side cooldown. This is a local-principal application, not a distributed authenticated service; a future multi-instance service needs shared quotas/authentication.

No lyrics or credentials are logged. Provider errors expose controlled messages/status/Retry-After; import/discovery validation logging omits payload/errors that might echo source. Optional credentials remain server-side. External detail cannot be submitted to `/imports`: the strict commit route accepts user input or an owner-bound signed personal receipt plus corrections and reparses corrections; caller-supplied provider documents/policy are rejected. Song create/update rejects preview-only documents and accepts validated personal-only LRCLIB sources. Copying material into an explicit user-content submission does not confer rights; the UI requires the user to confirm their own storage rights.
